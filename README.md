# DriverBee - Luxury On-Demand Chauffeur Platform

DriverBee is an on-demand personal chauffeur and driver platform that connects verified professional drivers with car owners. Book a background-checked chauffeur for flexible duration packages (2h, 4h, 6h, 8h, or custom hours) to drive your automatic, manual, or luxury vehicle.

## ✨ Key Features
- **Doorstep Driver Booking**: Reaches your doorstep in ~8 minutes.
- **Trip Types**: Within City Commutes & Outstation Road Trips.
- **Live Telemetry & Tracking**: Real-time driver map tracking, OTP handshake, and trip HUD countdown timer.
- **Chauffeur Showcase & Matching**: Filter verified drivers by rating, luxury specialty, and experience.
- **Driver Partner & Admin Portals**: Full driver operations portal and admin hourly pricing matrix configurator.
- **Ultra-Responsive UI**: Mobile and desktop design system with custom animations.

## 🚀 Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
python3 -m http.server 3000
```
Then visit `http://localhost:3000`.
